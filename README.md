# Certifications

Public repository for open badge `.png` images and public verification links.

## Badge Images

Certification badge PNG files are stored in the [`badges/`](badges/) directory and are publicly accessible via the raw GitHub URL:

```
https://raw.githubusercontent.com/WakiMak/certifications/web/badges/<badge-filename>.png
```

## Verifications

Each badge links back to its issuing certification authority for public verification. Verification URLs are provided alongside each badge in the directory listing below.

| Badge | Certification | Verification |
|-------|--------------|--------------|
| *(add badge filename)* | *(certification name)* | *(verification URL)* |

## Usage

To reference a badge image in a profile or document, use the raw GitHub URL shown above with the corresponding badge filename.
